# Support

This is a portfolio reference implementation, not a commercial component library with an availability commitment.

For reproducible defects, use the bug-report form and include a minimal reproduction plus environment details. For new APIs or components, use the feature-proposal form and explain the consumer problem, accessibility contract, alternatives, and maintenance cost. General implementation questions should first consult the README, generated component references, examples, architecture decisions, and existing issues.

Security-sensitive reports must follow [SECURITY.md](SECURITY.md). Do not disclose vulnerability details in public issues or discussions.
